# Portfolio redesign plan

## Direction

Reinterpret CRED's current monochrome, editorial visual language using original
typography, layouts, and vector artwork. Black and warm ivory; oversized serif
headlines; flat, spacious sections; tactile surfaces; restrained motion.

## Content priorities

1. Custom indicator-based algorithmic trading: NSE markets, WebSockets, Fyers
   and Kotak SDKs, historical backtesting, and forward paper trading.
2. Exchange-data Telegram automation with custom transformations and trader-group delivery.
3. Teaching basic Python to traders.
4. Enterprise agentic AI with current resume-backed outcomes.
5. JOT as a substantial open-source contribution, with verified Gmail integration
   work and direct source/contribution links.
6. Financial document intelligence, GraphRAG, and recommendation systems.
7. ASL only as an earlier-project link. Django is not a featured project.

## Verification and release

- Capture intermediate and final desktop/mobile screenshots.
- Check 320, 390, 768, 1024, and 1440 pixel widths for overflow and readability.
- Test menu, keyboard access, disclosures, navigation, resume, and external links.
- Validate source, commit, push, and verify GitHub Pages against the commit.

Preserve the resume PDF. Finance project descriptions come from the user's direct
account; no performance or trading-return claims are added. JOT attribution is
contributor, not sole author. Current resume numbers supersede older drafts.
